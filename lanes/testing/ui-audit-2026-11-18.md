# UI audit — 2026-11-18 (one UI kit for the whole product)

Cam 2026-11-18: "make sure the whole site is uniform … sliders, bubbles, animations, icons, buttons all need to look
the same page to page", across the course dashboard, admin, golfer pages and the homepage. Also a mobile overhaul
and animations that elevate the product, all before launch.

This is a read-only inventory of main at the date above (grep over `src/app` and `src/components`, `.tsx` and
`.css`). Counts are files / occurrences. The approved target is the UI kit mockup (the link goes in the PR body). Nothing here
changes code.

## Headline

There is no shared control layer. `src/components/ui/` has `Btn`, `Card`, `Modal`, `StatusDot`, `MonthPicker` and the
`INPUT` classes, but almost nothing uses them: `<Btn>` appears in **1 file** against **1,127 raw `<button>`s in
182 files**. Each page area re-types its own button, switch, tabs, toast and dialog. Uniformity therefore means
building the kit once in `src/components/ui/` and moving pages onto it, not restyling page by page.

## What the kit must provide (`src/components/ui/`)

`Button` (primary, secondary, quiet, danger, icon; sizes 36 and 44, where 44 is the default on phones and golfer pages), `Switch`,
`Stepper`, `Tabs` (sliding), `FilterButton` with a sheet, `Tag`, `StatusDot`, `Field` (input, search, select, date),
`Dialog` (a sheet on phones, centred on desktop; focus trap, Escape, scroll lock), `Toast` (one `Toaster`), `EmptyState`,
`Skeleton`, `LineRow`, and the motion tokens in `globals.css` (`--dur-tap`, `--dur-panel`, `--dur-slide`, `--ease`) with
a single reduced-motion switch. Every look (dashboard charcoal, dashboard Light, admin green, golfer light or dark plus accent) is
token swaps only, as DASH-D already requires.

## Migration order (proposal)

1. Kit plus tokens, with no page changes.
2. Golfer pages and the homepage (launch-facing, and mobile-first).
3. Dashboard.
4. Admin.

Each page moves in its own PR, with `scripts/glass-test.ts` and a new guard that fails on a raw `<button className=` outside
`src/components/ui` once a page has moved.
